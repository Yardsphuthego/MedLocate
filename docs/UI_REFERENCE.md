# Interface reference

The MedLocate interface is adapted from the layout language of the
[TEBELO smart city platform](https://github.com/Yardsphuthego/tebelo-smart-city-platform),
as requested by the project owner.

Reused design ideas include:

- an institutional information strip and compact primary navigation;
- a data-led landing page with a service console and capability rail;
- restrained `DM Sans` / `Manrope` typography;
- cards, tables, status chips and responsive staff workspaces; and
- clear public, authenticated and role-specific navigation layers.

MedLocate uses its own teal health-access palette, content hierarchy, component
CSS and templates. TEBELO's smart-city features, source assets, data model and
business logic are not included.

The global header and footer were subsequently adapted from the information
architecture of the [Cleveland Clinic website](https://my.clevelandclinic.org/),
at the project owner's request. MedLocate follows its utility-bar, spacious
service navigation, directory dropdown, multi-column footer and policy-bar
patterns, while retaining original MedLocate branding, copy, routes and styles.
Cleveland Clinic logos, artwork and site content are not included.
